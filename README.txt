PIXEL RPG ADVENTURE

КАК ЗАПУСТИТЬ:
1. Установи Node.js.
2. Открой папку rpg-game в VS Code.
3. Открой терминал в этой папке.
4. Выполни:
   npm install
   npm run dev
5. Открой адрес, который покажет Vite (обычно http://localhost:5173).

УПРАВЛЕНИЕ:
W A S D или стрелки — движение
Space или J — атака (пока декоративное действие)
E — поговорить со старейшиной (подойди к нему на площади)

КАК МЕНЯТЬ КАРТИНКИ:
Все игровые картинки лежат в public/images:
- player.png — герой
- tree.png — дерево
- house.png — дом
- rock.png — камень
- elder.png — старейшина
- monster.png — монстр

Можно заменить PNG-файлы своими картинками, сохранив те же имена.
Лучше использовать PNG с прозрачным фоном. Если меняешь размеры картинки,
масштаб на карте можно изменить в src/App.jsx в вызовах drawImage.

Размер мира: 3000 x 2200 игровых пикселей. Камера следует за игроком.
